Digital Image Processing

IP (Digital Image Processing) is the process of processing and analyzing digital images using mathematical techniques. It uses compression techniques such as DCT, DWT, and SVD to reduce image size while maintaining image quality and important information.

DCT DWT SVD

Discrete Cosine Transform

DCT (Discrete Cosine Transform) converts image data from the spatial domain into the frequency domain. It separates important low-frequency information from less important high-frequency details to reduce file size.

About It Project

Discrete Wavelet Transform

DWT (Discrete Wavelet Transform) decomposes an image into different frequency components and multiple resolution levels, separating important image information from less important details.

About It Project

Singular Value Decomposition

SVD (Singular Value Decomposition) decomposes an image matrix into three matrices (U, Σ, and Vᵀ). It compresses images by retaining the most significant singular values and removing less significant information.
