Digital Image Processing

DIP (Digital Image Processing) is the process of processing and analyzing digital images using mathematical techniques. It uses compression techniques such as dct, dwt, and svd to reduce image size while maintaining image quality and important information.

DCT DWT SVD

Discrete Cosine Transform

DCT (Discrete Cosine Transform) is an image compression technique that converts image data from the spatial domain into the frequency domain. It separates important low-frequency information from less important high-frequency details and removes unnecessary data to reduce image size.

About It Project

Discrete Wavelet Transform

DWT (Discrete Wavelet Transform) is an image compression technique that decomposes an image into different frequency components and multiple resolution levels. It separates important image information from less important details to reduce file size while maintaining image quality.

About It Project

Singular Value Decomposition

SVD (Singular Value Decomposition) is a mathematical technique that decomposes an image matrix into three matrices (u, σ, and vᵀ). It compresses images by retaining the most significant singular values and removing less significant information, reducing storage size while preserving image quality.
